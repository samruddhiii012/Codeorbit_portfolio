# 🚀 Samruddhi Harel | Portfolio Website

A modern, high-performance, and fully responsive personal portfolio website built with clean **HTML5, CSS3, and Vanilla JavaScript**, featuring custom canvas particle animations, glassmorphism cards, smooth two-way scroll-reveal animations, and an interactive certificate viewer modal.

---

## ✨ Features & Highlights

- **Sleek Deep Blue & Ice Tech Theme:** Designed with a professional dark mode palette (`#00002A` background with electric blue and ice accents).
- **Interactive Hero Particles:** Custom HTML5 canvas background rendering smooth floating bokeh/starlight particles with mouse tracking.
- **Two-Way Scroll Animations:** Elements smoothly animate into view when scrolling down and fade/slide back out when scrolling up using an optimized `IntersectionObserver`.
- **Dynamic Skill Badges:** Integrated official **Devicon SVG logos** for programming languages, frameworks, and developer tools.
- **Projects Showcase:** Highlights key developments including *TrafficIQ*, *Smart Library Intelligence System*, *EventFlow AI*, *CivicEye*, and the *CLOUD BME* research paper.
- **Credentials & Certificate Viewer:** Interactive modal popup to browse hackathon badges, published conference papers, and job simulation certificates.
- **Smooth Magnetic Buttons & Cursor Trail:** Micro-interactions adding a high-end feel to buttons and mouse movement.
- **Fully Responsive:** Optimized layout seamlessly adapting from mobile viewports to ultra-wide desktop screens.

---

## 🛠️ Tech Stack

- **Markup & Styling:** HTML5, CSS3 (CSS Variables, Grid, Flexbox, Glassmorphism)
- **Interactivity:** Vanilla JavaScript (ES6+, DOM Manipulation, Custom Canvas API, IntersectionObserver)
- **Icons & Assets:** Devicon (Official SVGs) & Google Fonts (*Bricolage Grotesque*, *Instrument Sans*, *JetBrains Mono*, *Playfair Display*)
